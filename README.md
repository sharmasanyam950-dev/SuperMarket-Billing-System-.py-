# 🛒 Supermarket Billing System (Python)

A simple **Supermarket Billing System** developed using **Python**.  
This project is designed for **beginners** to understand how Python can be used to solve real-life problems like billing and invoice generation.

---

## 📌 Project Description

The Supermarket Billing System automates the billing process by allowing users to enter multiple items along with their quantities and prices.  
The system calculates item-wise totals, applies discounts based on the total purchase amount, and generates a clean, itemized bill.

This project uses **basic Python concepts** such as lists, loops, and conditional statements.

## 🔄 How the System Works

1. User enters item name, quantity, and price  
2. Details are stored using Python lists  
3. Total price for each item is calculated  
4. Subtotal is computed  
5. Discount is applied based on total amount  
6. Final bill is displayed in a formatted table  

---

## 💸 Discount Rules

| Total Amount | Discount |
|-------------|----------|
| Above ₹5000 | 20% |
| Above ₹2000 | 10% |
| Above ₹1000 | 5% |
| Below ₹1000 | No Discount |
